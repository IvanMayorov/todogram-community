TikTok Sans (TikTok), one variable woff2 per subset as served by Google Fonts: latin, latin-ext, cyrillic, cyrillic-ext.
Axes: weight 300–900, width 75–150 %, optical size (auto). The app uses the width axis for hierarchy (--wd-head / --wd-list in app.css).
