# Todogram для macOS

Десктопный клиент открывает [Todogram](https://tasks.isite.pro/) в отдельном окне macOS. Верстка и стили загружаются с сайта через системный WebKit. Для работы нужен интернет.

## Установка версии 0.1.0

Сборка предназначена для Mac с Apple Silicon (M1 и новее). Откройте `Todogram-0.1.0-arm64.dmg`, перенесите Todogram в «Программы» и запустите. Нажмите «Войти через Telegram» и подтвердите вход в боте. Список задач откроется в окне приложения.

Эта сборка подписана локально (ad hoc). При скачивании из интернета Gatekeeper может заблокировать первый запуск. Для распространения с проверкой Apple потребуется сборка с подписью Developer ID и нотарификацией.

## Сборка из исходников

Для сборки на Mac нужны Rust и Xcode Command Line Tools. Установите CLI Tauri второй версии:

```sh
cargo install tauri-cli --version '^2' --locked
```

В каталоге с `tauri.conf.json` выполните:

```sh
cargo tauri build
```

По умолчанию приложение собирается для архитектуры текущего Mac. Файлы `.app` и `.dmg` появятся в `target/release/bundle/`.
